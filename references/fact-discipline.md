# 事实纪律

杂谈可以有观点、有猜测、有思想实验，但观众得分得清哪句是事实、哪句是推论、哪句是假设。分不清，整期视频的可信度就塌了。

## 1. 四类标签

写稿时每个强结论都要归到一类，标在段末的内部标注里。定稿时删标注，但口播的说法要让观众听得出是哪一类。

| 标签 | 是什么 | 口播里怎么让人听出来 |
|---|---|---|
| **FACT** | 能核实的事实和数据 | 直接陈述，带出处：「外汇局的数据是……」 |
| **INFERENCE** | 从事实推出来的结论 | 「所以我的判断是……很可能」「这说明」「大概率」 |
| **HYPOTHESIS** | 思想实验、假设推演 | 「假设一下」「我们做个思想实验」「假如」 |
| **USER VIEW** | 用户本人的直觉和观点 | 「我的判断是」「在我看来」「我一直认为」；用户原话本来是问句的，用设问引出（「问题就来了：……会不会……？」） |

**规矩：**

- INFERENCE 不能说成 FACT 的语气。「人民币升值会导致……」是推论，要说「人民币一涨，很可能会……」。
- HYPOTHESIS 里的数字是编的，口播要说是假设，画面要标「假设数字」。
- USER VIEW 不能为了好听改成定论。核实后发现站不住，讲成"常识 vs 数据"，不删也不硬撑，讲述者不认错。

## 2. 数字从哪来

- 稿子里的数字只从项目的核实表、来源总表里拿。
- 不沿用旧对话、旧稿、记忆里的数字，哪怕看起来很眼熟。
- 核实表里没有的数字，写「【待核实：要找的内容】」占位，写完稿统一交给用户或进入核实流程。
- 模型估算类的数字（比如「汇率被低估两成」）必须同时说明「这是模型估算，各家分歧很大」，并说清是谁估的。
- 「首次」「最大」「历史新高」「全球第一」这类最高级说法，必须有明确出处，否则改成不带最高级的说法。

**用户原话核对：** 引用用户原话、把某句话标成 USER VIEW 之前，回原始对话记录核对三件事：

- 原话是陈述还是问句。问句不能改写成"我一直觉得"。
- 它在回应什么：上一轮对方说了什么。脱离上下文，主语很容易搞错。
- 主语是谁：说的是哪个国家、哪类人。

AI 整理的"用户观点"文件、素材池，可能把 AI 自己的推演和金句也记成了用户的话，不能直接当用户原话用。

## 3. 来源怎么说

**来源优先级：**

1. 官方统计和监管机构（统计局、海关、外汇局、央行、各国统计机构）
2. 国际组织（IMF、世界银行、OECD、BIS、UNIDO 等）
3. 高质量学术研究
4. 新闻媒体，只用来补时效性事件，不作为核心机制的唯一依据

**口播里：**

- 说具体是谁：「外汇局的数据」「世界银行的报告」「德国央行的研究」。
- 不说「有数据显示」「研究表明」「专家认为」「有人说」。
- 引用某个机构的表态，说清在什么场合、以什么形式说的，措辞跟原文对得上。会议主席声明不能说成联合声明，财长会议不能说成峰会。
- 引用别人的观点时讲完整，不截取对论点有利的那一半。

## 4. 口径陷阱

写数字前对一遍：

- **名义和实际**：扣没扣物价？
- **同比和环比**：跟去年同期比，还是跟上个月比？
- **百分比和百分点**：利润率从 6% 降到 5%，是降了 1 个百分点，不是降了 1%。
- **存量和流量**：是一年新增多少，还是累计攒了多少？
- **对谁涨**：人民币对美元涨了，不代表对一篮子货币也涨了。
- **范围**：「规模以上工业企业」不等于「所有企业」，「组件产能」不等于「整个光伏产业链」。
- **时间段**：年份是自然年还是财年？数据截止到几月？

## 5. 数字念法

口播只念最关键的一两个数字，而且要念成耳朵听得懂的样子。精确值放画面。

| 原始数字 | 口播 | 画面 |
|---|---|---|
| 7,350 亿美元 | 七千多亿美元 | 7,350 亿美元 |
| 21% | 两成多 | 21% |
| 86% | 将近九成 | 86% |
| 从 200 万辆到 709.8 万辆 | 四年变成了原来的三倍多 | 200 万 → 709.8 万辆 |
| 利润率 6.81% → 5.31% | 卖 100 块钱的东西，能落下的从差不多 7 块变成 5 块出头 | 6.81% → 5.31% |
| 0.14 个百分点 | 只少一点点（不上屏或放角标） | 角标注明 |

**原则：**

- 能用成数（两成、将近九成）就不用百分比。
- 能用生活化的换算（「卖 100 块钱的东西落下几块」）就不用专业指标名。
- 不说「翻了 X 倍」，说「变成原来的 X 倍」。
- 精确到小数点的数字，口播一律取整或用「多」「出头」「将近」。

## 6. 时间说法和时效复查

- 「今年」「去年」「最近」这类相对时间可以用，生活感受类的开头尤其适合。但内部标注里要写明它指哪一年，导出前确认发布时间跟它还对得上。
- 讲数据时优先用具体年份，视频放久了也不会错。
- 内部标注里写「数据截至 YYYY 年 MM 月」。
- 时效性强的数据（汇率、贸易、利润、最新政策表态）在三个时间点各复查一次：写稿当天、录音前、导出前。变了就改稿，不能拿旧数字凑合。

## 7. 中立和敏感

- 不点名评价领导人。
- 不唱衰，不吹捧。不写「必然崛起」「注定失败」「被吊打」「遥遥领先」这类结论式说法。
- 讲国家之间的竞争，落点放在机制和普通人的处境上，不放在谁赢谁输上。
- 有争议的问题，正反两方都给出处，用「我更倾向于」表态，不替观众做最终判断。
