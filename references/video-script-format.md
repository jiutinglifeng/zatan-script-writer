# 视频脚本（分镜表）格式

逐字稿定稿后再拆。逐字稿没定就拆分镜，口播一改，分镜要跟着全改。

## 1. 分镜表模板

每段一张表，镜号格式是「段号-序号」（S01-01、S01-02……），和逐字稿、音频、剪辑工程用同一套段号。

```
## S01 段落工作名（预计 2:30）

| 镜号 | 口播 | 画面类型 | 画面说明 | 上屏数字/文字 | 字幕关键词 | 来源 | 素材难度/负责人 |
|---|---|---|---|---|---|---|---|
| S01-01 | （逐字稿原文，一镜一到三句） | 数据图 | 说清画面上有什么、怎么动 | 7,350 亿美元（不念） | 赚进来 | [F5-S11] | 低 / Claude |
```

**各列怎么填：**

- **口播**：逐字稿原文，一字不改。一镜通常一到三句，画面要换的地方就切镜。
- **画面类型**：从第 2 节的类型里选一个，有叠加时写「主类型 + 叠加」，比如「真人出镜 + 数字卡」。
- **画面说明**：写到剪辑或写代码的人不用再问就能做的程度。包括画面上有什么、元素出现的顺序、跟口播哪几个字对齐。
- **上屏数字/文字**：画面上出现的所有数字和文字。每个数字后面注明「念」或「不念」。
- **字幕关键词**：见第 4 节。
- **来源**：上屏的每个数字都要有来源编号，对应项目的来源总表。假设数字写「假设」。
- **素材难度/负责人**：见第 5 节。

段末附一行小结：这一段有几镜、几个数据图、几处需要用户提供素材。

## 2. 画面类型

| 类型 | 适合 | 注意 |
|---|---|---|
| **真人出镜** | 开头、改口、表达个人判断、结尾 | 讲观点和情绪的地方用，讲数据时别一直是脸 |
| **B-roll** | 生活场景、工厂、港口、街景，给口播配氛围 | 只是陪衬，不能让观众误以为是某个具体事件的画面 |
| **数据图** | 数字对比、走势、占比 | 规则见第 3 节 |
| **动画示意** | 机制和流程（钱怎么流、价格怎么传导） | 一个动画只讲一条因果链，箭头方向跟口播顺序一致 |
| **原件截图** | 官方报表、文件原文、新闻标题 | 高亮对应的那一行或那一句，标清出处和日期 |
| **AI 生图** | 没有现成素材的概念场景、假设场景 | 不能做成看起来像真实照片的新闻画面；假设场景要能看出是示意 |
| **标题卡/章节卡** | 段落开头、抛出段尾问题 | 用直白的问句，不用比喻 |

## 3. 数据图设计规则

- **一图一结论。** 图的标题直接写结论，比如「赚的美元很多，换成人民币的却很少」，而不是「2024 年结售汇数据」。
- **最关键的数字最大。** 有视觉层级，观众扫一眼就知道该看哪。
- **一屏最多三组对比。** 多了拆成两屏，或者按口播节奏一组一组出。
- **标签帮人认。** 国家配国旗，公司配 logo，产品配图标。
- **能回到原件就回到原件。** 报表原件做底，高亮对应的行，用连线把数字引出来放大。观众会觉得「这是真的查过的」。
- **跟着口播动。** 念到哪个数字，哪个数字才出来或高亮。在画面说明里写清对齐的字。
- **假设数字标出来。** 画面上明确写「假设数字」，用跟真实数据不同的样式（比如虚线框）。
- **来源角标。** 每张图右下角写机构和年份。
- **单位和口径写清。** 名义还是实际，对美元还是对一篮子，截止到哪个月。
- **配色统一。** 同一个国家、同一个指标，全片用同一个颜色。

## 4. 字幕关键词

除了逐句字幕，屏幕上有时会用大字强调一两个词。

- 每镜 0 到 3 个，不是每镜都要有。
- 选论点词，不选名词堆。「不换」比「结售汇」好，「越卖越不赚钱」比「利润率」好。
- 跟口播原文的用词一致，不另起炉灶。
- 改口的地方（「我一开始以为」）、段尾问题，优先给关键词。

## 5. 素材难度和负责人

| 难度 | 含义 | 例子 |
|---|---|---|
| **低** | 代码能直接生成 | 数据图、文字卡、动画示意、章节卡 |
| **中** | 公开可获取，需要找和截 | 官方报表截图、公开文件原文、免费素材库 B-roll |
| **高** | 需要实拍、授权、购买或用户本人提供 | 实拍场景、新闻视频片段、影视片段、私人照片 |

- 负责人写「Claude」「用户」或「待定」。
- 难度高的素材，在画面说明里同时给一个低难度的备选方案。
- 新闻视频、影视片段、他人作品涉及版权，默认不用，必须用时标出来让用户决定。

## 6. 示例

下面是一期经济话题视频开头的拆法，用来说明格式。

```
## S00 东西便宜了，厂子不挣钱，钱却变值钱了（预计 0:50）

| 镜号 | 口播 | 画面类型 | 画面说明 | 上屏数字/文字 | 字幕关键词 | 来源 | 素材难度/负责人 |
|---|---|---|---|---|---|---|---|
| S00-01 | 不知道你有没有这种感觉：这几年好多东西是真便宜了。以前二三十万的车才有的配置，现在十几万的车就能买到。 | 真人出镜 → 数据图 | 先出镜一句；念到「二三十万」时切到车价标签，从「25 万」翻成「15 万」 | 25 万 → 15 万（不念，示意） | 真便宜了 | 待补具体车型 | 低 / Claude；车型待用户确认 |
| S00-02 | 按理说，东西做得又好又便宜，做这些东西的厂子应该很赚钱吧？ | 真人出镜 | 出镜，语气是真的在问 | 无 | 应该很赚钱吧？ | — | 低 / 用户 |
| S00-03 | 可你要是问问身边在工厂、做外贸的人，很多人会跟你说：订单不少，就是不挣钱。 | B-roll | 工厂流水线，不出现可识别的具体企业 | 无 | 订单不少，就是不挣钱 | — | 中 / 待定 |
```

段末小结：本段 3 镜（节选），1 个数据图，车型旁证待用户确认。
